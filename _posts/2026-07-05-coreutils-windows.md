coreutils is a command line utility in attempts to sync unix commands to windows. Windows by defaulta does not come with unix commands and this utility helps sync to make unix like experience on windows terminals.

[core utils doc](https://learn.microsoft.com/en-us/windows/core-utils/commands)


## install

```text
winget install Microsoft.Coreutils
```
