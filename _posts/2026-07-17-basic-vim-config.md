Here is my super minimal .vimrc

.vimrc
```text
syntax on
set number

set tabstop=4
set shiftwidth=4 
set expandtab
set autoindent
set smartindent

set ignorecase smartcase
set incsearch hlsearch 
set wrap linebreak
set undofile
set noswapfile
```
